Privacy Policy

Effective 2026-11-05 · Operated by Beardworks (털보네공업사, sole proprietorship, Republic of Korea) · Covers: Naïl: Under the Roots (all versions), beardworks.io and its subdomains

In short

Our game and this website do not collect personal data. There are no accounts, ads, analytics or tracking cookies, and your progress is saved only on the device you play on. In the store versions (Steam and the Epic Games Store), the store processes your account data for achievements and cloud saves under its own privacy policy. The only personal data we receive is an email you choose to send us.

1. What the game saves on your device

  • Progress (save slots, unlocks, journal and so on) and settings (sound, language, controls and so on). No name, email or location is included.
  • Where: the browser's site storage (localStorage) for the web version; the app's save folder on the device for PC, Android and iOS.
  • This data is never sent to us. The game has no code that sends anything to a server of ours (the source code is public).
  • To delete it: erase a slot on the game's save slot screen, clear the site data in your browser, or uninstall the app.

2. What the stores process in the store versions

Steam version

  • The game talks to the Steam client to unlock achievements; if you use Steam Cloud, your save files are copied to Valve's servers.
  • The game reads your Steam account number only to name the save folder on your device (so several accounts on one PC keep separate saves). It does not send this number anywhere.
  • Controller and policy: Valve Privacy Policy

Epic Games Store version

  • The game signs in to your Epic account with the login the Epic launcher hands over, and unlocks achievements through Epic Online Services.
  • Epic processes your account identifier and basic profile (display name, language preference) for this. The game does not store this data or send it to us.
  • Controller and policy: Epic Games Privacy Policy

Purchases and payments are handled by each store. We only see the aggregate statistics a store shows developers (units sold, achievement rates and so on), never an individual buyer's payment details.

3. Website, web version and downloads

  • This website (beardworks.io and nail.beardworks.io), the downloads (APK and PC builds) and the source code are hosted by GitHub; the web version of the game is hosted by Netlify; DNS for the domain is handled by Cloudflare. The game page loads its latest news from GitHub.
  • When you visit, access logs such as your IP address and browser details may be kept in those companies' server logs. We do not receive or use those logs. Policies: GitHub · Netlify · Cloudflare
  • This website and the web version use no cookies. The web version stores (caches) the game files in your browser so it can start offline.

4. Emails to us

  • If you email support@beardworks.io (questions) or business@beardworks.io (work inquiries), we use your address and message only to reply. Mail is forwarded through Cloudflare Email Routing to the operator's Gmail and kept there (Google Privacy Policy).
  • Ask us to delete it once your question is answered and we will. We never use it for anything else or share it.
  • Anything you post on GitHub Issues is public on GitHub and covered by GitHub's policy.

5. Children

We do not ask for age and do not collect personal data from anyone, including children. If we learn that a child has emailed us, we delete the message after replying.

6. Your rights and contact

The only personal data we hold is email you sent us, and you can ask to see or delete it. For data in your store account, contact that store. Privacy contact: the owner of Beardworks, support@beardworks.io

7. Changes

If our game or website ever starts handling new data, we will update this page first and change the effective date. Earlier versions are in the change history.
